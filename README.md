# 스마트 체육수업 관리

동산초등학교 체육수업을 위한 스마트폰·PC 대응 웹 앱입니다.

## 스마트폰 세로 화면 사용

- 학급 선택: 360px 이상에서는 3열로 표시합니다. ‘학급 삭제 관리’를 눌렀을 때만 삭제 버튼이 나타납니다. 추가·전체 백업은 아래 접이식 메뉴에 있습니다.
- 하단 메뉴: 출석부 / 모둠 / 8자줄넘기 / 도장판. 학급 변경과 명단·백업은 상단에 있습니다.
- 출석부: 출석 버튼은 참석/불참, 이름은 다중 스톱워치 대상 선택, `•••`는 순발력·볼센스·메모·모둠 관리입니다. 이름/번호 검색과 정렬·불참 필터를 지원합니다. PC에서는 기존 표를 유지합니다.
- 모둠: ‘이동·더보기 → 모둠 이동 / 자리 교환’으로 목적지를 선택할 수 있습니다. 기존 길게 누르기·드래그 방식도 유지합니다.
- 저장 상태는 상단에 계속 표시합니다. ‘기기 저장’은 클라우드 저장 완료와 다릅니다.
- 줄넘기 작성 중 숫자는 탭/학급/주차 전환 및 자동 갱신에 보존됩니다. **임시 입력은 메모리에만 있으므로 새로고침·종료 전에는 기록 저장 버튼을 누르세요.** 저장한 기록의 기존 오프라인 복구 방식은 유지합니다.

모바일 레이아웃은 `mobile.css`, 화면 전용 상호작용은 `mobile-ui.mjs`로 분리했습니다. Firebase 인증·저장 방식과 엑셀 형식은 변경하지 않습니다.

## 접근 계정

앱과 Firestore 규칙 모두 `lws5737@seoul-dongsan.es.kr` 계정만 허용합니다. 클라이언트 검사만으로는 데이터가 보호되지 않으므로, Vercel 배포와 별도로 Firestore 규칙을 반드시 배포해야 합니다.

```bash
firebase login
firebase deploy --only firestore:rules
```

Firebase Authentication의 Google 로그인 제공업체와 Vercel 운영 도메인도 Firebase Console의 승인된 도메인 목록에 등록되어 있어야 합니다.

## Vercel

정적 사이트이므로 저장소를 Vercel에 연결해 배포할 수 있습니다. `vercel.json`은 기본 보안 헤더와 `index.html` 캐시 방지 설정을 적용합니다.

## 검사

```bash
npm test
```

검사는 허용 계정, Firestore 규칙, 학급 선택 첫 화면, CSV 인코딩 오류 및 누락된 HTML 이벤트 핸들러를 확인합니다.

### 브라우저 회귀 검사

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:ui
```

320/390/768/1440px에서 화면 잘림, 출석/검색/선택, 이동/교환, 터치 취소와 드롭, PC 드래그, 줄넘기 임시 입력 유지, 메뉴 전환을 검사합니다. `.ui-artifacts/`에 스크린샷을 저장합니다. Edge를 사용할 때는 `UI_BROWSER_CHANNEL=msedge` 환경 변수를 지정할 수 있습니다.

테스트 서버는 `127.0.0.1`에만 열립니다. Firebase 모듈을 테스트 응답에서만 대체하고 가상 학생 데이터를 사용하며 실제 Firebase/API 요청은 차단합니다. 운영 HTML과 인증 코드를 우회하거나 실제 학생 자료를 수정하지 않습니다.
